# Aha - User Story Map

## 用户旅程概览

### 用户角色
- **新用户**: 首次使用aha的用户
- **普通用户**: 已注册并开始使用功能的用户
- **高级用户**: 需要高级功能和集成的用户
- **管理员**: 系统管理员和团队管理员
- **B端开发者**: 需自主开发一款应用、或贡献功能模块并上架到应用广场


## 用户故事地图

### 1. 用户注册与登录

#### 1.1 新用户注册
**作为** 新用户  
**我希望** 能够快速注册账户  
**以便** 开始使用 Aha 的灵感记录功能

**验收标准:**
- 用户可以通过邮箱、手机号（前缀可选国家代码）注册
- 支持 Google OAuth 、微信、登录
- 注册流程简单，不超过3步
- 邮箱验证功能

1.2 用户登录
作为 已注册用户
我希望 能够安全登录系统
以便 访问我的灵感库和应用

验收标准:

支持邮箱密码登录

支持Google OAuth登录

30天免登录功能

生物识别登录（移动端）

1.3 用户资料管理
作为 用户
我希望 能够管理我的数字身份
以便 展示创造者形象

验收标准:

用户旅程地图
新用户旅程
发现Aha平台 → 快速注册 → 记录首个灵感 → AI生成应用 → 基础装扮空间 → 设置免费分享 → 获得首次点赞

普通用户旅程
登录空间 → 语音记录新灵感 → 拖拽开发应用 → 设置按次收费 → 购买动态皮肤 → 监控收益仪表盘 → 提现到微信

高级用户旅程
登录系统 → 发起协作项目 → 拼装教育应用套装 → 设置分润比例 → 发布到应用广场 → 管理团队资源 → 分析收益趋势

B端开发者旅程
登录开发者中心 → 创建功能模块 → 通过AI测试 → 上架到模块市场 → 监控被引用数据 → 接收自动分账 → 优化迭代模块

管理员旅程
登录管理后台 → 查看系统健康状态 → 审计团队资源使用 → 处理异常告警 → 更新平台规则 → 生成安全报告
